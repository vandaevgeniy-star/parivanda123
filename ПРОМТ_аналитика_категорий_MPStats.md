# Промт: аналитика категорий маркетплейсов (WB + Ozon, MPStats)

Скопируйте текст ниже в новую сессию, подставив список категорий и токен MPStats.
Промт воспроизводит методику файла «Аналитика_БТ_СВОД_2027_MPStats.xlsx».

---

Собери аналитику маркетплейсов Wildberries + Ozon по категориям: [СПИСОК КАТЕГОРИЙ] через API MPStats и оформи один Excel-файл «Аналитика_[ГРУППА]_СВОД_MPStats.xlsx». Работай без уточняющих вопросов, все данные — точные, потоварные.

ИСТОЧНИК ДАННЫХ — MPStats API (заголовок X-Mpstats-TOKEN, токен: [ВСТАВИТЬ ТОКЕН]):
- Потоварная выгрузка: POST /api/{wb|oz}/get/category?path=...&d1=...&d2=... с телом {"startRow":N,"endRow":N+1000,"sortModel":[{"colId":"revenue","sort":"desc"}]} — страницами по 1000 строк, до исчерпания товаров с ненулевой выручкой. Пути категорий подбери по дампам /api/{wb|oz}/get/categories; если нужного листа нет в дампе — проверяй путь живым запросом данных (глубокие листья работают, даже когда дамп их не показывает).
- Месячные тренды: GET /api/{wb|oz}/get/category/trends (d1=2023-01-01).
- Поисковые запросы: GET /api/{wb|oz}/get/category/by_keywords (отдаёт до 5000 самых частотных).

МЕТОДИКА РАСЧЁТА ВЫРУЧКИ (строго, без приблизительных данных):
- WB, периоды ДО 01.09.2025: выручка SKU = revenue (заказы, в ценах С СПП) × purchase% ЭТОГО товара ÷ 100; если у товара нет purchase — 90%.
- WB, периоды С 01.09.2025: выручка SKU = revenue_estimated (Insight-выкупы, с СПП).
- Ozon: revenue (заказы) — сопоставимо с WB, обе площадки в ценах со скидками.
- Окна: 2024 год; 2025 год = Σ(янв–авг: заказы×выкуп%) + Σ(сен–дек: revenue_estimated) — двумя отдельными выгрузками по границе; H1 2025; H1 2026. Динамика = период2/период1 − 1.
- ПРОВЕРКА СООТВЕТСТВИЯ категории и названия товара — трёхступенчатая: (1) фильтр подкатегории по признакам в названии; (2) строгий фильтр предмета: название обязано содержать маркер категории, а негативные маркеры (аксессуары, запчасти, чужие предметы) исключают товар, если стоят в названии раньше позитивного; (3) тест первичного предмета: товар исключается, если первичный предмет его названия принадлежит другой категории. Аксессуары исключены всегда. Итог проверки (проверено/оставлено/исключено + примеры) показывай в каждой вкладке.
- Отрицательной динамики 2024→2025 в категориях быть не должно — если получилась, перепроверь выгрузку и фильтры и найди причину.

ТРАФИК (показатель показов/спроса, отдельно WB и Ozon):
- Из by_keywords за последние 30 дней доступного периода. WB — частотность запроса по данным Wildberries (wb_count), Ozon — частота по данным MPStats (count).
- В сводку бери сумму только ЦЕЛЕВЫХ запросов — содержащих маркер предмета категории (товары «видны» и по чужим запросам через рекламу — их не считать). Полную «видимую» сумму показывай во вкладке справочно. Для подкатегорий, делящих одну категорию площадки, атрибутируй запросы тем же именным фильтром, что и товары.

СЕЗОННОСТЬ:
- Коэффициент месяца = средняя выручка этого месяца за 2024–2025 (WB+Ozon, из трендов) ÷ среднемесячная. Амплитуда = max/min; метка: >3 «острая», >2 «есть», >1.5 «умеренная», иначе «нет»; пики — топ-2 месяца.

СТРУКТУРА ФАЙЛА (openpyxl, оформление с заливками/границами, суммы в ₽):
1. Лист «СВОД»: строки-категории по группам, колонки: Категория (внутренняя ссылка на вкладку) | WB 2024 | WB 2025 | Динамика WB 24→25 | Ozon 2024 | Ozon 2025 | Динамика Ozon 24→25 | WB H1 2025 | WB H1 2026 | Динамика WB H1 | Ozon H1 2025 | Ozon H1 2026 | Динамика Ozon H1 | Ниша 2025 итого | Товаров ≥1 млн/мес | Трафик WB, запр./мес | Трафик Ozon, запр./мес. Сортировка внутри группы по выручке 2025, строки ИТОГО по группам. Категории должны быть взаимоисключающими (без двойного счёта в итогах).
2. Лист «Сезонность»: все категории × 12 месяцев, подсветка ≥1.2 зелёным / ≤0.8 красным, амплитуда, метка, пики.
3. Лист «Процедура расчёта»: полная методика словами (выручка, граница 01.09.2025, фильтры, трафик, сезонность, ограничения).
4. Вкладка на каждую категорию, разделы по порядку: ПРОВЕРКА СООТВЕТСТВИЯ → Выручка по периодам (2024/2025/H1'25/H1'26 с динамикой) → ТРАФИК (итог целевых + всего видимых + топ-10 запросов WB и Ozon) → СЕЗОННОСТЬ (12 месяцев с метками высокий/низкий сезон) → ТОП-10 БРЕНДОВ H1 2026 (сумма + % выручки, отдельно WB и Ozon) → РЕФЕРЕНСЫ (крупнейшие карточки уникальных брендов, текст ссылки = название бренда, ссылка на карточку) → ФОРМ-ФАКТОРЫ (доля выручки H1 2026 по конструктивным типам из названия) → СЕГМЕНТАЦИЯ по главной оси категории (мощность Вт / объём л / тип — извлекать из названия) → ЦЕНОВЫЕ СЕГМЕНТЫ (авто-границы по выручко-взвешенным квантилям) → ВСЕ ТОВАРЫ ≥1 млн ₽/мес (WB и Ozon отдельно: артикул, название, бренд, выручка/мес, сегмент, форм-фактор, ссылка на карточку).

ОРГАНИЗАЦИЯ РАБОТЫ:
- Дедуплицируй выгрузки: если несколько подкатегорий делят один путь площадки — качай путь один раз и раздели фильтрами по названию.
- Качай окна параллельно (несколько фоновых процессов), страница 1000 строк (больше — таймаут шлюза), с ретраями.
- Промежуточные расчёты сохраняй в JSON ({категория}_exact.json), чтобы сборку файла можно было повторить без перекачки.
- По готовности: проверь итоги (суммы групп, отсутствие отрицательной динамики 24→25, работоспособность ссылок), отправь файл в чат, закоммить и запушь в репозиторий.
